# S4 console blockers — 2026-09-07

**Do not fabricate.** The active 103-component tabletop core passes its placement and connection checks, but the console is incomplete and unrouted. See [console review](CONSOLE-REVIEW.md) for evidence, scope changes and LED behaviour.

The MPN is S4; that alone does not qualify the land pattern. |
